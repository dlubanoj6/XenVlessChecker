# ⚡ XenVlessChecker

Автоматизированный инструмент для Termux (Android), предназначенный для скачивания, парсинга, мультипоточной проверки и сортировки VPN-ссылок (`vless://`, `vmess://`, `ss://`) с использованием движка **sing-box**.

---

## 🚀 Быстрая установка (Быстрый старт)

Запустите **один скрипт в Termux**, который сам установит Python, `sing-box`, `termux-api`, скопирует репозиторий и настроит все зависимости:

```bash
pkg install -y git && git clone [https://github.com/dlubanoj6/XenVlessChecker.git](https://github.com/dlubanoj6/XenVlessChecker.git) && cd XenVlessChecker && bash install.sh

✨ Основные возможности
📱 Интерфейс на Rich: Интерактивное консольное меню с прогресс-баром, таймером работы и динамической карточкой итогов по центру экранного пространства по окончании проверки.

⚡ Настраиваемая скорость: При запуске вы можете вручную задать количество параллельных потоков (воркеров).

🔔 Уведомления Android: Отправка Toast-уведомлений и системных пушей в шторку Android по завершении проверки.

📊 Авто-сортировка: Все рабочие ссылки автоматически сортируются по пингу (от лучших к худшим) и сохраняются в отдельный файл.

📥 Авто-скачивание: Скрипт update.py самостоятельно собирает и обновляет списки ссылок из проверенных источников.


🛠 Порядок использования
1️⃣ Скачивание / Обновление ссылок
Запустите скрипт для загрузки свежих конфигураций:

'''bash
python update.py
