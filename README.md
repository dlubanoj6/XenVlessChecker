⚡ XenVlessChecker

«Fast VPN configuration checker for Termux / Android powered by sing-box»

XenVlessChecker — инструмент для Termux, который автоматически собирает VPN-конфигурации, распознаёт ссылки "VLESS", "VMess" и "Shadowsocks", проверяет их работоспособность через sing-box, измеряет задержку и сохраняет рабочие конфигурации, отсортированные от самых быстрых к самым медленным.

Проект рассчитан на запуск непосредственно на Android через Termux.

---

✨ Возможности

- 🔗 Поддержка "vless://", "vmess://" и "ss://"
- 🔐 Поддержка VLESS Reality / TLS
- 🌐 Поддержка WebSocket и gRPC
- ⚡ Многопоточная проверка конфигураций
- 🧵 От 1 до 64 потоков, по умолчанию — 24
- 📡 Проверка соединения через sing-box
- 📊 Измерение задержки подключения
- 🚀 Автоматическая сортировка рабочих конфигураций по скорости
- 🧹 Удаление дубликатов перед проверкой
- 📥 Автоматическое скачивание свежих списков конфигураций
- 🔄 Повторные попытки загрузки файлов при ошибках
- 📱 Android Toast и системные уведомления
- 🎨 Интерактивный терминальный интерфейс на Rich
- 📝 Отдельный лог ошибок "sing-box"
- 🗂️ Все входные ".txt"-файлы обрабатываются автоматически

📦 Установка

Быстрая установка

Открой Termux и выполни:

```bash
git clone https://github.com/dlubanoj6/XenVlessChecker.git
cd XenVlessChecker
bash install.sh
```

"install.sh" автоматически устанавливает необходимые пакеты Termux, "Python", "sing-box", "termux-api", создаёт директорию для конфигураций и устанавливает Python-зависимости.

Во время установки Termux может запросить разрешение на доступ к памяти Android.

Разрешение необходимо предоставить.

---

🚀 Использование

После установки перейди в каталог проекта:
```bash
cd XenVlessChecker
```
1. Обновить списки конфигураций
```bash
python update.py
```
Скрипт спросит:

Обновить списки? (yes/no):

При подтверждении старые файлы в:

/storage/emulated/0/links

будут удалены, после чего будут загружены актуальные списки из настроенных источников.

Скрипт использует GitHub API, отображает прогресс загрузки и повторяет неудачные загрузки до 3 раз.

---

2. Проверить конфигурации
```bash
python check.py
```
Скрипт найдёт все поддерживаемые ссылки в ".txt"-файлах:

vless://...
vmess://...
ss://...

Дубликаты автоматически удаляются.

После этого программа спросит количество конфигураций:

Сколько ссылок проверить?

и количество потоков:

Сколько потоков использовать?

Можно указать значение от 1 до 64.

Если просто нажать "Enter", будут использованы:

24 потока

---

⚡ Проверка скорости

Каждая конфигурация запускается через отдельный экземпляр "sing-box".

После запуска создаётся локальный SOCKS5-интерфейс, через который выполняется TCP-подключение к тестовому серверу.

Текущий порог успешной проверки:

≤ 2000 ms

Конфигурации, которые не устанавливают соединение или превышают этот порог, не попадают в итоговый список.

---

📊 Результат

Рабочие конфигурации сортируются по измеренной задержке:

fastest
   ↓
   ↓
   ↓
slowest

и сохраняются в:

/storage/emulated/0/links/output.txt

Например:

vless://...
vless://...
vmess://...
ss://...

Таким образом, в "output.txt" находятся только конфигурации, которые успешно прошли проверку.

🔗 Поддерживаемые протоколы

VLESS

Поддерживаются различные варианты VLESS, включая:

- TCP
- WebSocket
- gRPC
- TLS
- Reality
- uTLS
- SNI
- ALPN
- "flow"
- "serviceName"
- "shortId"
- "publicKey"

Конфигурация VLESS преобразуется в формат "sing-box" перед проверкой.

VMess

Поддерживаются:

- TCP
- WebSocket
- gRPC
- TLS
- SNI
- ALPN
- uTLS

Shadowsocks

Поддерживаются стандартные "ss://" конфигурации с URL-safe Base64 и обычным форматом credentials.

🗃️ Рабочая директория

Все списки конфигураций находятся здесь:

/storage/emulated/0/links/

Основные файлы:

links/
├── *.txt
├── output.txt
└── singbox_errors.log

"*.txt"

Входные файлы с VPN-конфигурациями.

"output.txt"

Итоговый список рабочих конфигураций, отсортированный по задержке.

"singbox_errors.log"

Лог ошибок при проверке конфигураций.

---

⚙️ Настройки

Основные параметры находятся в "check.py".

Например:

MAX_DELAY_MS = 2000
CONNECT_TIMEOUT = 3.0
SINGBOX_START_TIMEOUT = 5.0

Максимальная задержка

MAX_DELAY_MS = 2000

Конфигурации с большей задержкой считаются слишком медленными.

Таймаут подключения

CONNECT_TIMEOUT = 3.0

Максимальное время ожидания подключения.

Запуск sing-box

SINGBOX_START_TIMEOUT = 5.0

Максимальное время ожидания запуска локального SOCKS5-интерфейса.

⚠️ Важно

XenVlessChecker проверяет доступность VPN-конфигураций и не гарантирует:

- стабильность соединения;
- скорость передачи данных;
- доступность всех сайтов;
- отсутствие блокировок;
- работоспособность конфигурации спустя некоторое время.

Результат проверки отражает состояние конфигурации на момент тестирования.
